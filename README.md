# Practicing Hero Animation 🚀

A Flutter practice project focused on creating smooth Hero animations between product listing and product detail pages.

This project helps me understand how Hero animations work in Flutter and how to create smooth transitions while navigating between screens.

## ✨ Features

- Smooth Hero animations between pages
- Product listing UI
- Product detail screen
- Navigation between screens
- Product data using a Dart model class
- Interactive and user-friendly UI

## 🛠️ Built With

- Flutter
- Dart
- Material Design
- Hero Animation
- Navigator
